## Proyectos destacados

### ERP de Gestión de Desguaces
ERP modular para la gestión de vehículos fuera de uso, baterías, residuos, facturación y trazabilidad documental. Arquitectura basada en 9 microservicios Laravel, bases de datos independientes, Redis, Docker, Nginx y CI/CD.

[Ver proyecto](https://github.com/danimatper/erp-desguace-microservicios)

### Sistema de Gestión de Albaranes
Aplicación web en producción para digitalizar el ciclo completo de albaranes de transporte: creación desde oficina, cumplimentación y firma desde móvil, generación automática de PDF, control de existencias e integración con ERP.

[Ver proyecto](https://github.com/danimatper/gestion-albaranes)

### Plataforma de Gestión de Transporte y Comercialización de Cereales
Proyecto Final de Ciclo de DAM, calificado con 10 y Matrícula de Honor. Aplicación móvil en Flutter conectada a un backend Laravel para automatizar cálculo de rutas, costes de transporte, comparación de orígenes y generación de ofertas comerciales.

[Ver proyecto](https://github.com/danimatper/transporte-cereales-tfc)

### Digitalización Documental con Inteligencia Artificial
Herramienta para automatizar la clasificación y digitalización de facturas y albaranes escaneados mediante modelos de visión de OpenAI y Gemini, incluyendo interpretación de numeración manuscrita.

[Ver proyecto](https://github.com/danimatper/digitalizacion-documentos-ia)
