## Proyectos destacados

### Gresiduos — Plataforma Multiempresa de Gestión de Residuos

Aplicación web multiempresa en producción para gestores de residuos. Gestiona contratos, documentos de identificación, archivo cronológico, stock por código LER, tratamientos, PDFs y auditoría.

Arquitectura basada en Next.js, React, TypeScript, Supabase y PostgreSQL, con aislamiento multiempresa mediante Row Level Security, roles, funciones transaccionales, documentos inmutables y testing automatizado.

[Ver proyecto](https://github.com/danimatper/gresiduos-gestion-residuos)

---

### Albaranes + DeCA Digital

Sistema Laravel en producción para digitalizar albaranes de transporte y el Documento electrónico de Control Administrativo (DeCA).

Integra oficina y conductores mediante enlaces móviles seguros, actualización de pesos, generación de QR y PDF, versionado inmutable, control de entrega y protección frente a ediciones simultáneas.

**Stack:** Laravel 13, PHP 8.4, MariaDB, Docker, DomPDF, FPDI, PHPUnit, Dusk, Larastan.

[Ver proyecto](https://github.com/danimatper/albaranes-deca-digital)

---

### Digitalización de Documentos con IA

Automatización desarrollada en Python para procesar facturas y albaranes escaneados mediante visión artificial.

El sistema separa documentos, identifica proveedores y números de factura, interpreta numeración manuscrita y genera automáticamente PDFs correctamente nombrados.

**Stack:** Python, PyMuPDF, Pillow, OpenAI Vision, Gemini.

[Ver proyecto](https://github.com/danimatper/digitalizacion-documentos-ia)

---

### Plataforma de Gestión de Transporte de Cereales

Aplicación móvil Flutter conectada a un backend Laravel para calcular costes de transporte, comparar orígenes, generar ofertas y gestionar contactos comerciales.

Integra Google Maps para obtener distancias reales por carretera y centraliza la lógica de negocio en una API REST.

Proyecto Final de Ciclo de DAM, calificado con 10 y Matrícula de Honor, actualmente utilizado en un entorno empresarial real.

[Ver proyecto](https://github.com/danimatper/transporte-cereales-tfc)

---

### Dashboard de Contratos — Automatización Excel

Herramienta Python que transforma un Excel empresarial con múltiples hojas y cientos de registros en un dashboard HTML interactivo.

Detecta contratos activos utilizando incluso el formato y color existente en el Excel, genera indicadores, filtros, búsquedas y exportación CSV sin obligar a la empresa a cambiar su forma de trabajar.

**Stack:** Python, openpyxl, HTML, CSS, JavaScript.

[Ver proyecto](https://github.com/danimatper/dashboard-contratos)
